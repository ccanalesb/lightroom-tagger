Five ways to add a provider

This page asks one question: which of these should the Providers tab actually do? Every option below adds the same kind of provider and stores the same fields — they differ only in how you say which provider you want. Try each one. They all work.

The stepper from the previous prototype is deliberately not here; it turned adding a provider into an onboarding flow. Behind all five, adding a provider is a single operation: check the address, ask what models it has, send each one a test image, report back.
